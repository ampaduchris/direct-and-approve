# Security policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting: the "Report a vulnerability" button on the Security tab of this repository. Please do not open a public issue for a vulnerability.

## Scope

This repository holds documents and scripts that read and copy text files. A way to make `scripts/extract.py` write a file that holds a private marker, or to make it write outside its output folder, is a vulnerability. A procedure that you judge to be weak is not: open an issue.

## Supported versions

Only the latest release.
