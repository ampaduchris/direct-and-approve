# The answers

The answers are public, so this set is for demonstration only. Anyone who has read these files has not been calibrated by them.

- `EXPECTED.md` names the planted defect in each example and the command that exposes it.
- `prove.py` runs every command on every example and checks the result against what `EXPECTED.md` says. It writes its transcript to `PROOF.txt` in the system temporary folder. The `PROOF.txt` here is the transcript of one earlier run.
